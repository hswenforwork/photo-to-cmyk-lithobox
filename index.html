關於本工具

本工具為純前端網頁應用，所有影像處理（含AI主體偵測、日式似顏繪風格轉換）都在您的瀏覽器本機完成，照片不會上傳到任何伺服器。原始碼可直接部署於 GitHub Pages 等靜態託管服務：把整個資料夾（index.html 與 assets/）上傳到您的 GitHub repo 並開啟 GitHub Pages 即可，無需任何後端伺服器。

使用的第三方套件與模型、授權、致謝

  • AI主體偵測：U²-Net輕量版模型（來自 danielgatis/rembg 專案，Apache-2.0授權），透過 onnxruntime-web（Apache-2.0授權）在本機執行，首次使用約需下載19MB模型資料，瀏覽器快取後可離線使用。
  • 日式似顏繪風格AI：CartoonGAN圖像風格轉換模型（MIT授權，權重來自 Yijun Li 等原作者，經TensorFlow.js格式轉換），透過 TensorFlow.js（Apache-2.0授權）在本機執行，每種畫風首次使用約需下載13MB模型資料。此AI函式庫執行時需要頁面CSP開放'unsafe-eval'，僅影響本頁自身程式碼執行彈性，不影響「照片不上傳到任何伺服器」的連線限制（connect-src僅允許同網站內資源）。
  • PDF壓縮：fflate函式庫（MIT授權），用於PDF內部影像資料FlateDecode壓縮。
  • CMYK印刷色域描述檔：PDF內嵌「Japan Color 2011 Coated」ICC描述檔（取自 ICC色彩描述檔登錄資料庫，授權允許使用/嵌入PDF/交換/分享，檔案內容未經修改）作為PDF的OutputIntent，讓支援的印刷軟體/RIP知道CMYK數值對應的印刷條件依據；首次下載PDF時瀏覽器會另外下載約1.9MB描述檔並快取，下載失敗時仍會正常產生PDF，只是不含這項宣告。RGB→CMYK本身採標準數值公式換算（K=1-max(R,G,B)等），不是經過ICC色彩管理的轉換。
